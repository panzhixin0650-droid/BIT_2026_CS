# 数据库验证

在仓库根目录运行：

```bash
database/tests/run.sh
```

脚本只依赖 Bash 和 SQLite 3。它在 `/tmp` 下创建全新的临时数据库，依次执行首个迁移、两次演示种子和只读验收，再执行“预约 → 开始 → 停止并扣款”事务冒烟，最后验证手机号、外键、当前订单唯一性、订单状态与时间顺序及金额公式的失败分支。临时数据库在脚本退出时删除，不会写入仓库。

完成 schema 1 基线验证后，脚本执行 002 工单迁移，比较原五表导出内容保持不变，
验证提交去重、状态/回复约束、事务回滚、重复迁移拒绝以及完整性和外键。
`verify_support_tickets.sql` 面向该脚本的新临时库，不应对已有工单的业务库直接执行。

随后执行 003 管理员迁移，比较用户、站点、电桩、订单和工单的导出内容不变，
并验证原管理员身份／密码摘要保留、角色默认值、完整性、外键及重复迁移拒绝。
另建临时库验证缺失 002 时拒绝升级，以及旧账号不满足新约束时整笔迁移回滚。
`verify_admin_accounts.sql` 同样仅用于演示测试库，不用于实际业务库验收。

`verify_demo.sql` 也可以单独对已经初始化且仍为 schema 1 的开发库执行：

```bash
sqlite3 -batch -bail build/database/demo.db < database/tests/verify_demo.sql
```
