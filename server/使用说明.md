# 服务端管理员端使用说明

> 适用版本：管理员账号管理未发布版及后续兼容版本
> 适用范围：`server-app` 内的 Qt 管理员端
> 面向对象：充电站运营管理员、验收人员和维护本仓库的 Agent

本文说明管理员端当前已经落地的页面、操作方式和业务限制。界面上的操作文字以当前程序为准；如果代码、接口或业务规则发生变化，应先更新本文，再进行用户验收和 Agent 联调。

## 1. 启动与登录

### 1.1 启动前提

默认使用已初始化的 SQLite 数据库。服务端兼容 schema 1/2/3，拒绝缺失、未知版本或
版本与表结构不匹配的数据库。新库先执行 001、基础／扩容种子及基线验证，再依次执行
002 工单和 003 管理员迁移。已有库先停服、备份，再补缺失的后续迁移，不能重跑 001 或种子。
具体步骤见 [数据库说明](../database/README.md)。未升级 003 的旧库仍可固定账号登录，
但隐藏管理员管理并禁用改密；schema 2 的工单仍可使用。

在仓库根目录构建并启动：

```bash
cmake -S server -B build/server -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build/server
./build/server/server-app --database build/database/demo.db
```

只查看管理员窗口时可以加 `--no-tcp`。默认监听本机 `127.0.0.1:45678`；`--in-memory` 仅用于测试或数据库尚未准备好的开发场景，进程退出后数据不会保留。

在 Qt Creator 中运行 CMake 后，将运行目标切换为 `server-app`，再点击运行按钮。不要把协议测试目标当作管理员窗口启动。

### 1.2 登录

登录页采用蓝色能量线条背景，左侧为悦充品牌，右侧填写管理员账号和密码。使用本地演示数据库时，可使用仓库 README 中给出的演示管理员账号；正式环境请使用实际分配的管理员凭证，不要把凭证写入界面截图、提交记录或公开文档。

登录失败时保留已填写内容，按照错误提示修正后重试。退出登录位于左侧导航栏底部；退出后会清空页面浏览历史，下一次登录从默认页面开始。

系统创建的新管理员带有“待修改初始密码”标记，首次登录只能修改密码。密码修改成功后当前会话立即结束，需要使用新密码重新登录。已有演示管理员第一次成功登录时会自动升级旧密码摘要，不要求额外操作。

### 1.3 模拟充电自动完成

`server-app` 启动后启用每次 180 秒的模拟充电。用户可在客户端“充电”页提前结束；
到期由服务端复用停止与结算流程，释放电桩并尝试钱包扣款。余额不足时保留待支付订单。
客户端离线不影响此流程，服务端重启后会补处理已经到期的充电订单；重复检查不会重复扣款。
管理员可在订单管理查看最终时长、电量、金额与状态。本规则不新增表，不重置已有数据库。

## 2. 页面导航

左下角仅显示当前管理员的显示名。左侧按总览、资产管理、业务服务、系统管理分组，最多包含八个模块，按账号角色和数据库功能显示；模块切换不会改变数据库数据：

| 页面 | 用途 |
| --- | --- |
| 运营监控 | 查看电桩状态分布和各站点电桩汇总 |
| 营收统计 | 查看营收指标和按日期的营收趋势 |
| 充电站管理 | 管理站点、站点状态及站内电桩从属关系 |
| 充电桩管理 | 管理电桩资料、状态和设备操作 |
| 用户管理 | 查询用户并冻结或解冻账户 |
| 订单管理 | 查询订单并查看完整订单信息 |
| 客服工单 | 仅系统管理员可查看用户反馈、回复并更新状态 |
| 管理员管理 | 创建和维护管理员账号、角色、状态及站点范围 |

角色权限如下：

| 角色 | 页面与操作范围 |
| --- | --- |
| 系统管理员 | 全部页面；可创建和维护管理员，管理全部站点、电桩、用户和订单 |
| 站点管理员 | 运营监控、营收统计、充电站、充电桩和订单；数据及写操作限授权站点，不能新增或删除站点 |
| 用户管理员 | 营收统计、用户和订单；可冻结或解冻用户，不能管理站点、电桩和管理员 |

权限由服务端业务层校验，隐藏菜单只用于减少误操作。管理员账号被停用后，后续操作会被拒绝；重新登录也会失败。

### 2.1 单击、双击与右键规范

- 普通表格（充电桩、用户、订单）：单击只选中当前行；双击打开居中的详情窗口；右键打开当前行的操作菜单。
- 充电站主表：单击主行展开或收起站内电桩；双击主行打开站点详情；右键打开站点操作菜单。
- 充电站展开后的电桩子行：只显示编号、类型、功率、状态；双击跳转到充电桩管理，自动按所属站点筛选并高亮目标电桩；右键可查看电桩详情或前往电桩管理。
- 空白区域右键不会显示业务菜单。

单击展开和双击详情已经分开处理。操作站点展开时，请点击行左侧的树形小三角或单击主行；不要连续快速点击并把一次双击误当成两次展开操作。

### 2.2 详情窗口

详情窗口居中显示，不是右侧固定栏。窗口会根据内容尽量紧凑，内容较多时在窗口内部滚动；窗口内点击不会关闭，点击窗口外任意区域关闭。当前版本不提供单独的关闭按钮。

详情页会重复列表中的关键字段，并补充创建时间、坐标、累计数据、订单时间等适合深入查看的信息。详情页中的信息用于查看，不等于可以修改；可修改字段请使用右键菜单中的编辑操作。

### 2.3 后退、刷新、前进

页面顶部的工具组顺序为：后退、刷新、前进。

- **后退/前进**：只恢复之前浏览过的页面视图，不撤销任何数据库操作。保存的视图包括页面、搜索字段、关键词、多选筛选、站点展开状态、选中项、电桩定位和营收日期范围。
- **刷新**：整个内容区会短暂淡入并显示顶部加载线，然后恢复完整内容；重置当前页面的搜索、筛选、展开或日期配置，并重新读取当前页面数据；不修改数据库，不刷新其他页面，也不把刷新动作写入历史。
- **浏览历史不是数据撤销**：新增、编辑、删除、启用/停用、开机/关机、重启和故障标记等操作一旦保存，不会被后退或前进恢复。

例如，从运营监控点击“故障”跳到充电桩管理后，可以后退回到原来的运营监控；再点击前进，可以恢复充电桩管理及其筛选和高亮位置。

## 3. 搜索、筛选与重置

搜索和筛选是两个独立条件，可以单独使用，也可以同时使用；同时使用时按 AND 关系过滤结果。

### 3.1 搜索

搜索框左侧先选择搜索字段，关键词输入后即时刷新结果，不需要额外点击搜索按钮：

| 页面 | 可选字段 |
| --- | --- |
| 充电站管理 | 站点名称、地址、全部 |
| 充电桩管理 | 电桩编号、所属站点、全部 |
| 用户管理 | 手机号、昵称、全部 |
| 订单管理 | 订单号、用户手机号、电桩编号、全部 |
| 管理员管理 | 管理员账号或显示名称 |

“全部”表示在该页面支持的字段中进行匹配，不代表绕过其他筛选条件。

### 3.2 多选筛选

筛选按钮位于搜索框附近。点击后在下拉弹窗中勾选一个或多个条件，可以使用“全选”；选择完成后点击“确认”统一应用。弹窗没有单独的“取消”按钮，未点击确认时不会应用本次选择。

当前筛选项包括：

- 充电站管理：区域、站点状态；
- 充电桩管理：所属站点、电桩状态；
- 用户管理：用户状态；
- 订单管理：订单状态、充电模式。
- 管理员管理：角色、账号状态。

区域选项来自当前账号可查看的实际站点数据，新增区域在刷新后自动出现，重复区域只显示一次。
筛选面板限制宽高，选项较多时在中间滚动，“全选”和“确认”固定在上下方；长名称悬停可看完整内容。

筛选按钮上的数字表示已选条件数量。搜索条件和筛选条件可以任意组合；例如先搜索“浑南”，再筛选“启用”，只显示名称或地址匹配且状态为启用的站点。

### 3.3 重置

点击“重置”会清空当前页面关键词、恢复搜索字段为“全部”、清除全部筛选并恢复页面默认视图。充电站管理的重置还会收起所有站点并将“全部展开/全部收起”恢复为“全部展开”。重置只影响当前页面，不删除或修改数据。

## 4. 运营监控

顶部指标显示运营中/全部站点、可用空闲桩、充电中/预约中、故障/离线数量。
可用空闲桩仅统计运营中站点。

- 电桩状态环形图：空闲为青绿、充电中为蓝、预约为紫、离线为琥珀、故障为红。
  悬停显示数量及占比；点击扇区或图例进入充电桩管理并筛选该状态。
- 站点占用率分布：按 100%、70%–不足 100%、40%–不足 70%、20%–不足 40%、低于 20% 五档统计站点数量。分子为预约及充电中电桩数，分母为全部桩数；无桩站点不参与分档。点击扇区或图例按占用率筛选站点。
- 异常电桩站点 Top 8：按故障与离线合计降序排列，同时显示两种数量。
- 订单当前状态：显示全部可见订单的当前状态构成，包含历史已完成和已取消订单。

运营监控上方以“当前时间”为标签显示北京时间，每秒更新；切回页面立即校准。时钟独立于数据加载，运营数据仍通过右上角刷新更新。

向下滚动可查看各站点的电桩汇总表。条形图悬停可看完整站名及数值。

## 5. 营收统计

页面提供“近 7 日”“近 30 日”“近 60 日”“近 90 日”和“自定义”范围。选择自定义后填写起始日期和终止日期，
再点击“应用”；包含起止两天，起始日期不能晚于终止日期。

第一排指标明确表示今日、本月、累计实收及站点/电桩数量；第二排表示所选区间的实收、
已支付订单数、这些订单的电量和平均每单实收。日期区间位于内容区左上角，与右侧日期筛选同一行，采用 20 px 中等字重和 `yyyy.MM.dd — yyyy.MM.dd` 格式；自定义日期输入单独一行，
不再显示原先的汇总说明行。

区间内的六张图为每日实收、站点实收 Top 8、每日支付单数、每日已支付订单电量、
直接/预约充电实收占比、已支付订单启动时段。按北京时间支付日期取数，启动时段则将这些
已支付订单的启动时间按 4 小时分组，缺少启动时间的不计入时段图。

折线按日补零，悬停显示日期、数值与单位；环形和条形图可悬停查看详细数值。
向下滚动可看全部图表。无数据和读取失败有独立提示；这些页面不提供利润或历史在线率估计。

### 5.1 图表动画触发规则

运营监控与营收统计在每次登录后的首次进入时播放图表出场动画。左侧切去其他页面再回来，
以及右上角后退/前进都不重复播放。手动刷新时会重新播放；营收切换近 7/30/60/90 日、应用自定义日期时也播放。
环形顺时针展开、折线从左到右显现、条形从基线伸展，约 0.9 秒结束；数值和标签始终表示实际数据。
切走页面立即结束动画，连续刷新不排队。客服工单、其他管理页同样有内容区刷新反馈。

## 6. 充电站管理

### 6.1 列表与从属关系

站点主行显示 ID、站点、区域、可用/总数、在线率、电价和运营状态。ID 固定在第一列，表头列不可拖动。点击站点主行可展开或收起所属电桩；也可以使用工具栏的“全部展开/全部收起”按钮：当前有任意展开项时按钮执行全部收起，否则执行全部展开，并同步显示当前动作。

展开后的子行只显示电桩编号、类型、功率和状态，字号和行高略小于主行以保持层次。双击子行会进入充电桩管理并定位目标电桩。

### 6.2 新增站点

点击右上角“新增充电站”，填写站点名称、区域、详细地址、经度、纬度和统一电价。初始电桩数量可以为 0；数量大于 0 时，表单下方立即生成相同数量的电桩明细，逐项填写或修改编号、类型和额定功率后一起提交。

站点 ID、创建时间和初始状态由服务端生成。提交成功后列表读取服务端返回的真实 ID，并自动展开新站点；如果当前搜索或筛选条件使新站点不可见，应清除条件后再查看。

### 6.3 右键操作

站点主行右键菜单提供：查看详情、管理站内充电桩、编辑充电站信息、新增充电桩、启用/停用充电站和删除站点。

- **管理站内充电桩**：跳转到充电桩管理，并筛选当前站点。
- **编辑充电站信息**：在中央表单中修改站点名称、区域、地址、坐标和电价；ID、创建时间等系统字段不能修改。
- **新增充电桩**：直接打开新增电桩表单，并预选当前站点。
- **删除站点**：站点有任何订单历史时不能物理删除；没有订单时才会在确认后级联删除站点及其全部电桩。

### 6.4 启用与停用

停用站点前，站内不能存在已预约或正在充电的电桩；否则操作会被拒绝，并提示结束相关业务后重试。停用成功后，空闲且在线的电桩自动变为离线；故障电桩仍保持故障，原本离线的电桩仍保持离线。重新启用站点不会自动启动这些电桩，需要在充电桩管理中显式执行上线。

## 7. 充电桩管理

列表显示 ID、电桩编号、所属站点、类型和状态。双击电桩行打开详情；右键可查看详情、定位到充电站、修改电桩信息、开机/上线、关机/下线、重启、标记故障和删除。

右键“定位到充电站”会清除站点页可能遮挡目标的搜索与筛选，跳转到充电站管理、展开所属站点，
选中并滚动到当前电桩。后退可返回原电桩列表，前进会重新恢复站点展开及子桩选中状态。

新增电桩时必须选择一个已启用的充电站，填写唯一的电桩编号、类型（快充/慢充）和额定功率。电桩 ID 由服务端生成，初始状态为“空闲”。从停用站点或空选择不能创建电桩。

修改电桩时只能修改编号、类型和额定功率；预约中或充电中的电桩不能编辑。设备状态操作遵循以下规则：

| 操作 | 允许条件 | 结果 |
| --- | --- | --- |
| 开机/上线 | 离线 | 变为空闲 |
| 关机/下线 | 空闲 | 变为离线 |
| 重启 | 空闲或离线 | 完成 Mock 重启；最终为空闲 |
| 标记故障 | 空闲或离线 | 变为故障 |
| 删除 | 空闲或离线且无订单限制 | 二次确认后删除 |

已预约或充电中的电桩不能关机、重启或删除。故障状态不能通过普通上线或重启清除，需等待后续检修/报修流程。电桩有订单历史时不能物理删除，以保留订单关联。

## 8. 用户管理

列表只显示管理员日常判断所需的 ID、手机号、昵称、余额和状态。双击用户行查看包含注册时间、订单总数和累计消费等信息的详情；右键可查看详情或冻结/解冻账户。

有进行中订单的用户不能被冻结。冻结或解冻成功后，列表会重新读取最新状态。

## 9. 订单管理

列表显示订单 ID、订单号、用户手机号、站点、电桩、模式、状态、金额、创建时间和支付时间，默认按创建时间从新到旧排列，同一时刻按订单 ID 降序排列。双击订单行打开完整详情，详情中可查看用户 ID、站点/电桩 ID、创建/预约/开始/结束/支付时间、时长、电量、价格快照和金额；右键还可以复制订单号；具有资产管理权限的管理员可选择“管理该充电站”或“管理该充电桩”，按订单关联 ID 定位。站点页自动展开并选中该电桩，电桩页选中对应记录；返回会恢复订单筛选及所选订单。

订单列表的搜索和筛选只改变当前查看结果，不会改变订单状态，也不能通过后退、前进或刷新撤销订单业务。

用户端通过 TCP 产生的预约、取消、充电、停止结算和补支付已进入同一 SQLite 数据库。需要查看新结果时，刷新当前订单、充电桩或营收页面；当前没有服务端主动推送刷新。充电中的订单详情读取当前模拟进度，已结束订单显示保存的最终账单。

订单最小联调步骤与状态说明见 [`order-flow.md`](order-flow.md)。用户充值后补付待支付订单只改变订单与余额，不会干预该桩后来接收的新预约或充电。

### 9.1 客服工单

扫一扫报修也进入此页：列表显示“报修”和桩编号，详情显示故障类型。报修需要执行
[004 增量迁移](../database/migrations/004_repair_tickets.sql)，具体步骤见[数据库说明](../database/README.md)。
系统管理员沿用本页回复和状态操作，用户在“我的工单”刷新查看。报修不要求已有订单，
提交或解决均不会自动停止充电、免单或恢复故障桩；已关联报修的桩不能删除或改名。

关联了具体桩编号的报修工单，在“问题详情”右上方提供“定位电桩”。点击会跳转充电桩管理，
清除可能遮挡目标的搜索/状态条件，按所属站点筛选并高亮该电桩；目标不可查看时提示原因。
普通咨询工单没有设备关联时不显示此按钮，不从自由文本中猜测桩号。后退会重新读取工单，
恢复原工单选择，包括之前通过“加载更多”找到的工单；离开前请先保存正在编辑的回复。

这是独立的工单处理页面，不改变原有表格的单击、双击和右键规则。
选中左侧工单后，在右侧上方查看问题详情，下方选择状态、填写回复，点击“保存处理结果”。
左侧“已加载”表示当前已读取的工单数量；回复区显示当前字数。
状态为待处理、处理中、已解决；回复最多 2000 字，标记已解决时必须填写回复。
保存失败保留当前输入。只有保存才生效，切换条目或刷新前请先保存正在编辑的回复。

右上角导航中的“刷新”重新读取最新 10 条，“加载更多”继续加载；用户在客户端“我的工单”刷新后
可看到管理员回复。没有自动推送，没有自动退款、修桩或改订单；工单的“已解决”仅表示
管理员记录的处理结果。退出登录会清空已加载的工单和回复草稿，并撤销工单处理授权。

## 10. 管理员管理与密码

只有系统管理员可以看到并进入“管理员管理”。列表显示账号、显示名称、角色、站点范围、状态、待改密标记和最近登录时间；输入关键词会即时匹配账号或显示名称，角色和状态筛选可组合使用。

点击“新增管理员”填写账号、显示名称、初始密码和角色。初始密码为 6–128 个字符，允许纯数字，两次输入需一致。站点管理员必须至少选择一个站点；系统管理员和用户管理员不能附带站点范围。账号不区分大小写且不能重复。创建成功后将初始密码通过安全渠道交给使用者，使用者首次登录后必须自行修改。

双击管理员行查看只读详情；右键菜单提供“查看详情”和“修改管理员信息”。编辑显示名称、角色、状态或站点范围时必须填写原因；保存会整体覆盖该账号原有站点范围。当前登录的系统管理员不能停用自己或修改自己的角色，系统也会阻止停用或降级最后一名启用的系统管理员。

左侧底部的“修改密码”适用于所有角色。需要输入当前密码和两次新密码；新密码长度为 6–128 个字符，允许纯数字，且不能与当前密码相同。成功后程序退出当前管理员会话，使用新密码重新登录即可。

## 11. 常见问题

### 新建的数据没有出现在列表

先检查当前关键词、搜索字段和筛选条件。新增成功后列表会按当前条件显示；如果新数据不符合条件，点击“重置”即可查看完整列表。

### 点击详情后关闭，站点又展开或收起

当前版本双击站点主行只打开详情，单击展开由独立的单击判定处理。若仍出现异常，先确认是双击主行而不是点击左侧小三角，并重新启动最新构建的 `server-app`。

### 站点无法停用

检查站内是否有“已预约”或“充电中”的电桩。结束相关业务后才能停用；空闲、故障和离线状态本身不会阻止停用。

### 电桩无法上线或重启

故障电桩不能通过普通上线或重启恢复；已预约或充电中的电桩也不能执行关机、重启和删除。请按当前状态对应的操作规则处理。

### 后退后数据没有恢复到修改前

这是设计如此。后退/前进只恢复页面浏览配置，不撤销数据库写入。若要修改数据，请使用对应页面的编辑、启用/停用或设备操作。

## 12. Agent 协作规范：启动服务端时必须告知使用说明

这是仓库级协作要求，不是可选建议：

1. 任意 Agent 收到用户“启动服务端”“启动 server-app”或等价请求时，必须先阅读本文件，确认启动命令、当前页面交互和已知限制与当前代码一致。
2. Agent 必须在回复中明确告知用户：服务端使用说明书位于 [`server/使用说明.md`](使用说明.md)。
3. Agent 必须同时简要复述主要用法，至少包括：
   - 普通表格单击选中、双击查看详情、右键打开操作；
   - 充电站主行单击展开/收起，展开电桩双击跳转并高亮；
   - 搜索即时生效，筛选支持多选并点击确认，搜索与筛选可组合，重置清空当前页面条件；
   - 顶部后退/刷新/前进只处理页面视图，不撤销数据；
   - 详情窗口点击外部关闭，窗口内部点击不会关闭。
4. 如果启动失败，Agent 仍需先说明使用说明书位置和上述主要交互，再报告具体错误、检查结果和下一步建议；不能只粘贴终端日志。
5. Agent 不得把本说明书中的浏览历史描述成数据库事务撤销，也不得向用户承诺当前版本不存在的管理员功能、导出能力或远程管理接口。

推荐的启动回复最少包含以下信息：

> 服务端使用说明书：[`server/使用说明.md`](使用说明.md)。主要操作是普通表格单击选中、双击看详情、右键更多；充电站主行单击展开，子桩双击跳转并高亮；搜索会即时生效，筛选支持多选后确认，重置清空当前页面条件；顶部后退/刷新/前进只恢复页面视图，不撤销数据；详情窗口点击外部关闭。服务端已启动/启动失败，具体状态见下方。

管理界面的时间统一使用北京时间，格式为 `yyyy-MM-dd HH:mm:ss`，适用于管理员最后登录、账号详情、用户注册、订单各阶段与工单时间；未发生的时间显示“—”，未登录过的账号显示“从未登录”。营收区间仅显示日期。接口及数据库仍保留 UTC ISO 8601 格式。

总览顶部统计数字与图表同步播放 0.9 秒载入动画，数字从零递增，金额小数位和单位保留；首次进入、手动刷新、营收日期应用时播放，普通返回不重播。切页或重新取数立即结束上一段动画，时钟独立更新。所有多选筛选的选项滚动区与弹层采用统一浅蓝灰背景。

订单管理的“时间”筛选位于“模式”和“重置”之间，按钮风格与其他筛选一致。弹层提供近 24 小时、近 7/30/60/90 天和自定义，时间范围只能单选，点击“确认”应用。所有时间范围按订单支付时间筛选，快捷范围从当前时刻向前滚动计算；自定义在同一弹层选择北京时间的起止日期与时分秒，包含两个端点。未支付订单在不限时间时可见，选择支付时间范围后排除。无效范围在弹层内提示，不改变已有结果；关闭弹层丢弃未确认编辑。历史导航恢复已应用范围，清除/重置/刷新恢复不限时间，可与搜索、状态和模式组合。

总览支持点击查看明细：营收卡片、每日趋势、站点实收、充电模式、启动时段均打开订单管理，直接设置支付时间、已完成状态、站点、模式或启动时段筛选；站点与时段筛选也可在订单页面调整。运营卡片提供对应站点/电桩入口，双数值卡片点击后选择具体类别；异常图进入该站故障与离线电桩，订单状态饼图进入对应订单，汇总表点击站名查看站点、点击数量查看对应电桩。后退恢复总览日期和滚动位置，不重播动画。卡片支持回车/空格，图表支持方向键选择、回车/空格查看明细；无资产管理权限的用户管理员不可通过卡片进入资产页面。
