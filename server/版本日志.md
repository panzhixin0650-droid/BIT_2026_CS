# 服务端版本日志

本文档只记录 `server/` 服务端与同进程管理员端已经完成并验证的版本，不负责客户端、数据库或 Web 模块的版本。后续服务端版本更新继续写在本文件中，不另建版本日志。

## 维护规则

- 新版本写在旧版本上方，保留所有历史版本内容；
- 每个版本必须记录版本号、完成日期、主要新增、调整、验证结果和已知限制；
- 版本号由团队确认后再填写，未完成的内容不能写入“已完成”；
- 网络接口发生变化时，同时更新 [`服务端网络接口.md`](服务端网络接口.md) 和正式契约 [`../contracts/overall-interface-v1.md`](../contracts/overall-interface-v1.md)；
- 数据库接入、跨模块协议变更等内容应注明对其他负责人的影响。

## v2.0

完成日期：2026-09-04

版本基线：GitHub PR #12 合并提交 `044a728`（`feat(server): 管理端 v1.2 站点与电桩管理优化`，分支 `server/admin-v1.2`）。本地随后完成服务端同进程管理员端的管理体验、导航状态、运营监控和站点状态业务规则升级。本版本只记录 `server/` 范围内的服务端和 Qt Widgets 管理员端变更。

Git 核对：当前 `origin/main` 为 `a8b5250`（PR #14，客户端腾讯地图导航）；`044a728..origin/main` 期间没有新的服务端提交。客户端地图、Web 大屏及客户端 TCP 充电接口不属于本服务端 v2.0。

### 已完成内容

#### 管理后台结构与视觉统一

- 将原数据概览拆分为“运营监控”和“营收统计”两个独立页面，左侧导航保持原有风格并统一六个管理入口的层级。
- 统一充电站、充电桩、用户、订单四个管理列表的字体、表头、行高、列间距、控件字号和页面标题；充电站主行与展开后的电桩子行保持明确的主从层级，子行使用更紧凑的字号和行高。
- 调整侧边栏图标、平台标题、导航文字和页面标题的大小及布局，保持侧边栏宽度不变，提升整体可读性和轻量感。
- 清理管理页面中不必要的开发阶段提示、技术实现信息和重复说明，继续遵循 `uidesign.md` 的面向运营人员设计原则。

#### 统一列表交互与详情查看

- 建立统一的桌面端列表交互模型：
  - 充电站主行单击展开/收起，双击查看站点详情，右键打开更多操作；
  - 充电站展开的电桩子行双击跳转到充电桩管理并高亮定位；
  - 充电桩、用户和订单列表单击选中、双击查看详情、右键打开更多操作。
- 移除拥挤的列表操作列依赖，将详情、编辑、状态操作、删除等功能集中到右键上下文菜单。
- 将站点、电桩、用户、订单详情从右侧停靠面板改为居中的结构化窗口，按字段分组显示，窗口根据内容自适应并支持较长内容滚动。
- 详情窗口支持点击窗口外区域关闭，窗口内部点击不会误关闭；关闭后保留原列表的搜索、筛选、展开和选中上下文。
- 站点展开区域的电桩只保留编号、类型、功率和状态四项摘要信息，不重复显示扩展统计或设备操作。

#### 搜索、筛选与列表状态

- 为充电站、充电桩、用户和订单增加搜索字段选择：站点名称/地址、电桩编号/所属站点、手机号/昵称、订单号/用户手机号/电桩编号，并支持“全部”。
- 搜索与离散筛选彻底分离：关键词按当前字段即时匹配，区域、状态、站点和模式通过独立的多选筛选菜单生效；两者可单独使用，也可按 AND 关系组合。
- 多选筛选支持全选、取消勾选和确认应用，弹窗不再提供单独的“取消”按钮；重置会同时清空关键词、恢复搜索字段、清除所有筛选并恢复页面默认状态。
- 充电站管理增加“全部展开/全部收起”合并按钮：当前存在展开项时执行全部收起，否则执行全部展开，并同步显示下一步状态。
- 修复站点筛选、充电桩站点筛选、订单筛选和筛选控件布局问题，避免筛选条件在刷新或页面切换时丢失。
- 禁止充电站表头列拖动，固定列顺序和布局，避免误操作破坏主从树表结构。

#### 页面浏览历史与刷新

- 在顶部加入统一的“后退 ←、刷新 ⟳、前进 →”工具组。
- 后退和前进保存并恢复页面及其配置，包括当前页面、搜索字段、关键词、筛选条件、站点展开集合、选中项、电桩定位和营收日期范围。
- 浏览历史只记录页面视图状态，不记录新增、编辑、删除、启停、重启或故障标记等数据库操作，因此不会把前进/后退误用成数据撤销。
- 刷新只重置当前页面的界面配置并重新读取当前页面数据，不刷新其他页面、不写入浏览历史、不修改数据库；刷新后仍可继续使用已有的前进/后退历史。
- 登出时清空浏览历史，重新登录从默认运营监控页面开始。

#### 运营监控与营收统计

- 运营监控增加电桩状态环形图，统计空闲、在用、离线和故障数量，并在下方提供按站点汇总的电桩统计表。
- 环形图保持左侧布局，右侧图例只显示颜色和状态名称；鼠标悬停扇区或图例时显示状态、数量/总数和占比，点击扇区或图例均可跳转至充电桩管理并按状态筛选。
- 营收统计保留近 7 日、近 30 日和自定义日期范围，营收折线图悬停时显示具体日期和金额并高亮对应数据点；移除与营收无关的右侧状态卡。

#### 站点与电桩业务规则

- 充电站右键菜单增加编辑站点信息、管理站内电桩、新增电桩以及启用/停用站点等操作；编辑使用中央表单窗口并保留现有站点字段校验。
- 新增电桩必须选择有效的启用充电站；编号唯一，创建后站点电桩数量由关联数据自动聚合。
- 电桩右键菜单增加修改电桩信息，可修改编号、类型和额定功率；预约中或充电中的电桩禁止编辑。
- 停用充电站前由 `ApplicationService` 统一检查站内电桩：存在预约中或充电中的电桩时拒绝停用，站点状态保持不变。
- 停用成功后，站内空闲且在线的电桩自动切换为离线；故障电桩和原已离线电桩保持原状态。
- 重新启用充电站不会自动恢复或启动离线电桩，设备上线仍由管理员显式执行；故障状态不能通过普通上线或重启操作绕过。

### 调整内容

- 管理员 UI 的站点、电桩、用户和订单操作继续通过 `AdminFacade -> ApplicationService -> IRepository`，不让 UI 直接访问 SQL 或 Repository。
- 站点状态联动使用现有站点/电桩状态枚举和 `IllegalOrderState` 错误码，新增业务消息 `STATION_HAS_ACTIVE_PILES` 用于明确提示停用失败原因。
- 内存 Repository 与 SQLite Repository 共用同一套业务语义；未新增数据库表、字段、迁移或客户端 TCP 消息。
- 本版本没有新增数据库表、字段或迁移，也没有新增客户端 TCP 接口；管理员端新增的编辑、状态和页面导航能力均为进程内管理边界。
- 新增状态图组件和详情窗口等 Qt Widgets 实现，保持管理员端与服务端同进程运行方式不变。

### 验证结果

- `cmake --build build-server-Desktop-Debug -j2` 编译通过；
- `charging_server_tests` 全部通过，覆盖站点停用安全规则、电桩生命周期、站点/电桩管理和既有用户订单规则；
- `charging_repository_tests` 全部通过，SQLite 种子读取、聚合、持久化和安全删除验证通过；
- `charging_protocol_tests` 全部通过，长度帧、拆包/粘包、信封和 DTO 验证通过；
- `git diff --check` 通过；
- 使用 `build/database/demo.db` 重启 `server-app`，SQLite 仓储模式和管理员窗口启动正常。

### 已知限制与后续工作

- 管理员功能仍是服务端进程内 `AdminFacade` 调用，不提供管理员 TCP 登录或远程管理接口；客户端 V1 TCP 契约未因本版本改变。
- 当前仍使用既有五表数据库结构，不包含 RBAC、管理员账户/角色/权限体系、故障报修工单闭环和真实充电桩设备协议。
- 站点及展开电桩仍使用同一个 Qt 树表表头，子行通过缩进、字号、行高和背景区分；后续可在数据量增大时评估独立子表。
- 站点停用仅处理状态安全和空闲桩联动下线，不会自动取消预约、结束充电订单或恢复故障设备。

- Qt 6/C++17 `server-app` 编译通过；
- `charging_server_tests` 和 `charging_protocol_tests` 全部通过；
- `charging_repository_tests` 在临时 SQLite 数据库上全部通过；
- 使用现有 `build/database/demo.db` 完成管理员窗口无显示启动冒烟。

### 已知限制与后续工作

- 当前五表数据库结构未变更。

## v1.0

完成日期：2026-09-03

### 已完成内容

- 建立 Qt 6.2、C++17 服务端工程，生成 `server-app`、服务端测试和共享协议测试目标；
- 建立 `QTcpServer`/`QTcpSocket` 服务，默认监听 `127.0.0.1:45678`；
- 完成长连接所需的 4 字节大端长度帧、JSON 请求/响应信封、粘包和拆包处理；
- 完成服务端分层：`TcpGateway -> RequestRouter -> ApplicationService -> IRepository`；
- 完成客户端当前可联调的 8 个 TCP 接口：
  - `system.ping`；
  - `auth.user.login`、`auth.logout`；
  - `user.profile.get`、`user.profile.update`；
  - `wallet.recharge`；
  - `station.list`、`station.detail`；
- 建立数据库接入前的 `InMemoryRepository`，提供管理员、用户、充电站、充电桩和订单演示数据；
- 建立内存 token 会话，支持用户登录鉴权和退出；
- 建立 `MockPile` 和 `MockPredictionProvider` 开发边界；
- 完成 Qt Widgets 管理员界面：
  - 管理员登录；
  - 数据概览、7/30 日营收趋势和电桩状态；
  - 充电站查询与新增；
  - 充电桩列表与模拟重启；
  - 用户查询、冻结与解冻；
  - 订单列表；
- 管理员界面通过 `AdminFacade -> ApplicationService -> IRepository` 访问业务数据，不直接操作 Repository 或 SQL；
- 完成 Dashboard JSON 原子导出能力；
- 补充服务端和共享协议自动化测试。

### 验证结果

- Qt 服务端工程配置、编译成功；
- `charging_server_tests`：17 项通过；
- `charging_protocol_tests`：17 项通过；
- 管理员窗口可启动，TCP 服务可在 `127.0.0.1:45678` 正常监听；
- 已通过真实 TCP 冒烟验证登录、站点列表、站点详情和充值链路。

### 已知限制与后续工作

- 当前使用内存数据，进程退出后新增站点、余额和状态修改会丢失；
- SQLite Repository 尚未接入正式业务查询，后续由数据库实现替换内存 Repository；
- `prediction.latest` 和订单主流程 TCP 接口仍未接入 `RequestRouter`；
- 管理端当前与服务端同进程，通过 `AdminFacade` 调用，不提供管理员 TCP 接口；
- 当前只面向课程 Demo，不包含真实充电桩、RBAC、高并发、工单和复杂计价。
