# 服务端版本日志

本文档只记录 `server/` 服务端与同进程管理员端已经完成并验证的版本，不负责客户端、数据库或 Web 模块的版本。后续服务端版本更新继续写在本文件中，不另建版本日志。

## 维护规则

- 新版本写在旧版本上方，保留所有历史版本内容；
- 每个版本必须记录版本号、完成日期、主要新增、调整、验证结果和已知限制；
- 版本号由团队确认后再填写，未完成的内容不能写入“已完成”；
- 网络接口发生变化时，同时更新 [`服务端网络接口.md`](服务端网络接口.md) 和正式契约 [`../contracts/overall-interface-v1.md`](../contracts/overall-interface-v1.md)；
- 数据库接入、跨模块协议变更等内容应注明对其他负责人的影响。

## v1.0

完成日期：2026-09-03

### 已完成内容

- 建立 Qt 6.2、C++17 服务端工程，生成 `server-app`、服务端测试和共享协议测试目标；
- 建立 `QTcpServer`/`QTcpSocket` 服务，默认监听 `127.0.0.1:45678`；
- 完成长连接所需的 4 字节大端长度帧、JSON 请求/响应信封、粘包和拆包处理；
- 完成服务端分层：`TcpGateway -> RequestRouter -> ApplicationService -> IRepository`；
- 完成客户端当前可联调的 8 个 TCP 接口：
  - `system.ping`；
  - `auth.user.login`、`auth.logout`；
  - `user.profile.get`、`user.profile.update`；
  - `wallet.recharge`；
  - `station.list`、`station.detail`；
- 建立数据库接入前的 `InMemoryRepository`，提供管理员、用户、充电站、充电桩和订单演示数据；
- 建立内存 token 会话，支持用户登录鉴权和退出；
- 建立 `MockPile` 和 `MockPredictionProvider` 开发边界；
- 完成 Qt Widgets 管理员界面：
  - 管理员登录；
  - 数据概览、7/30 日营收趋势和电桩状态；
  - 充电站查询与新增；
  - 充电桩列表与模拟重启；
  - 用户查询、冻结与解冻；
  - 订单列表；
- 管理员界面通过 `AdminFacade -> ApplicationService -> IRepository` 访问业务数据，不直接操作 Repository 或 SQL；
- 完成 Dashboard JSON 原子导出能力；
- 补充服务端和共享协议自动化测试。

### 验证结果

- Qt 服务端工程配置、编译成功；
- `charging_server_tests`：17 项通过；
- `charging_protocol_tests`：17 项通过；
- 管理员窗口可启动，TCP 服务可在 `127.0.0.1:45678` 正常监听；
- 已通过真实 TCP 冒烟验证登录、站点列表、站点详情和充值链路。

### 已知限制与后续工作

- 当前使用内存数据，进程退出后新增站点、余额和状态修改会丢失；
- SQLite Repository 尚未接入正式业务查询，后续由数据库实现替换内存 Repository；
- `prediction.latest` 和订单主流程 TCP 接口仍未接入 `RequestRouter`；
- 管理端当前与服务端同进程，通过 `AdminFacade` 调用，不提供管理员 TCP 接口；
- 当前只面向课程 Demo，不包含真实充电桩、RBAC、高并发、工单和复杂计价。
