# 开发环境模拟相册

“扫一扫 → 从相册识别”在应用内打开此目录的图片网格，用于 Ubuntu 下模拟手机选图。
点选一张照片，可先预览，再点击“识别”。取消返回相机；选图本身不创建充电订单。

“我的 → 更换头像”共用此目录和相册网格，点击“设为头像”后返回个人页并保存到本机；
取消保留原头像。头像选图不检查二维码内容，基础构建也提供这个入口。

已放入 6 张纯文本充电桩二维码：`PILE-A-01`、`PILE-A-02`、`PILE-B-02`、
`PILE-B-03`、`PILE-B-04`、`PILE-B-05`。图片由 qrencode 生成，与 workplace 测试二维码相同。
电桩是否存在、是否空闲仍由当前服务端数据库判断。

另有 3 张不含二维码的普通照片：`sample-coffee.png`（咖啡）、
`sample-landscape.png`（湖畔风景）、`sample-plant.png`（绿植），用于测试选错照片时的
“未发现二维码”提示。照片由内置 image_gen 生成，提示词见 [IMAGE_PROMPTS.md](IMAGE_PROMPTS.md)。

可以直接向此目录添加 PNG、JPG/JPEG、BMP 或 WebP 图片，再重新打开相册，无需重启或编译。
单张图片不超过 20 MB、3200 万像素；不可读取的文件不展示，无二维码图片会在识别时提示。
应用不会把照片上传到服务器，也不会打开二维码里的网址。

构建时的源码目录不存在时，使用打包内置的 9 张样例（6 张二维码、3 张普通照片）。若要把新增照片一并打包，
请更新 [album_resources.qrc](../resources/album_resources.qrc) 并重新构建。
开发和测试也可通过 `CHARGING_DEMO_ALBUM_DIR` 指定另一个本地相册目录。
本页是模拟相册；以后接入 Android/iOS 系统相册时，可继续使用现有选图后的解码与确认流程。
