# Agent entry point

Before planning or changing this repository, read and follow [`PROJECT_RULES.md`](PROJECT_RULES.md). Those shared rules are the canonical instructions for Codex and every other coding agent.

Use `$bit-charging-dev` for project work. Then read `docs/INDEX.md` and only the baseline/extension documents relevant to the user's requested scope. Do not treat `docs/extension/` as active requirements unless the user explicitly promotes a feature.

Use `$team-git-flow` for local Git synchronization, task branches, commits, pushes, pull requests, and post-merge cleanup.
