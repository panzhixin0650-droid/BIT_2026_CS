# ADR-0006：API 路线数据与自有交互地图

- 状态：Accepted（用户已授权实现，待合并）
- 日期：2026-09-06
- 授权：用户要求不用腾讯完整导航网页，改为 API 数据、自有布局，并支持放大缩小。

## 决策

四种方式统一由客户端直接调用腾讯 WebService `driving/walking/transit/bicycling`，
解析默认推荐方案的距离、预估分钟数、折线和分步说明。公交分别解析步行段与公共交通段，
使用每段第一条完整线路的坐标、线路名、上下车站和服务返回的运营警告；不把不同段拼成
虚构直线，不生成班次、票价或实时通行保证。分钟数向上取整，不把小数分钟截为零。

此决策取代 [ADR-0003](0003-client-transit-navigation.md) 的驾车/公交 URI 页面方案，
并统一 [ADR-0004](0004-client-cycling-navigation.md) 的步行/骑行地图绘制。
原有出行方式和 Mock 语义不变。

Qt 原生控件管理起终点、出行方式、距离用时、可折叠的纯文本路线详情和地图操作栏。
本地 HTML 仅承载 JavaScript API GL 底图、分段折线与起终点标记，不加载 `routeplan`
整站页面。仍需 Qt WebEngine，并非去掉浏览器渲染引擎或新增原生移动地图 SDK。

- 同一 SDK 配置下复用地图；腾讯模式在首屏显示后异步下载、解析 SDK，进入导航页后才
  在可见画布创建地图，让底图初始化与路线请求并行；重新规划只更新几何数据，不重新
  初始化文档。预加载不请求路线或传递当前位置，失败保持静默，首次真实导航会接管在途
  加载或重新尝试；Mock 模式不创建 WebEngine、不访问网络。
- 提供放大、缩小、滚轮缩放、拖动、双击放大、显示全程。按钮改变地图 zoom，
  不改变 WebEngine 的网页缩放比例或 Qt 文字大小。
- 地图占用剩余空间，详情限制高度并可滚动；取消原先 360 像素硬下限。
- API 请求期间和地图初始化期间均阻止重复点击；地图初始化有 15 秒超时。
  SDK 脚本缺失、初始化异常或渲染进程终止均恢复操作并提示失败，不能只凭 HTML
  `loadFinished` 就宣称地图可用。地图画布就绪不保证全部远端瓦片已下载。
- 点击导航返回、换站点或退出登录时取消在途路线/起点解析请求，旧结果不覆盖新目的地。
  切换底部主入口只暂时隐藏导航页：保留路线、地图实例与缩放状态，暂停已就绪网页，
  返回“充电”入口时恢复同一画布并校正尺寸。失败初始化允许重新创建，并提供显式重载；
  重载复用已取得的路线数据，不重复请求路线 WebService。
- 地图错误按可观察阶段区分脚本地址、内置页面、SDK 下载/接口、地图初始化、路线绘制、
  WebEngine 渲染进程和 15 秒超时；提示可能原因与对应检查方向。可恢复错误显示“重新加载
  地图”，路线摘要和文字详情在地图失败时继续可用。

## 边界

只修改 `client/` 的本地地图适配与 UI，并同步契约 §8.3、本地 fixture 和文档。
不修改 TCP 消息、共享业务 DTO、订单计费、服务端或数据库。位置和路线不入库；
Key 继续仅来自本地环境配置，不提交到仓库。Mock 不访问公网，不伪造真实路线。
这是路线规划与交互查看，不包含持续 GPS 定位、偏航重算或语音导航。

## 验证

离线测试覆盖四种方式、公交分段、异常数据、失败与取消；Qt 窗口测试覆盖最小窗口、
路线详情展开、旧响应丢弃。启用 WebEngine 时，使用本机 HTTP SDK 替身执行真正的
自有 HTML，验证启动预加载、首条路线复用、静默失败重试、Mock 零预加载、缩放上下限、
显示全程、跨主入口保留地图、文档复用、分类错误、显式重载和控件尺寸。
替身不能验证腾讯 SDK 的实际服务、网络速度或显卡帧率；这些仍需有效 Key 实机验收。
