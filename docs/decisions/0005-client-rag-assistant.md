# 0005：用户端只读 RAG 智能助理

- 状态：IMPLEMENTED；本次用户明确接受并授权实现第一版。
- 消费者/负责人：Qt 用户端；外部模型适配、知识检索和会话均在 `client/`。
- 背景：将“客服助理”预留页升级为聊天界面，接入用户指定的中转站与
  `gpt-5.6-luna`，提供项目知识库和一键问题。

## 决策

1. 采用随客户端发布的、可审阅的 JSON 知识条目，先做中文关键词/二元词检索，
   选取最多三条相关知识，再通过 HTTPS Responses API 生成回答。首版不引入
   向量数据库、embedding 服务或训练平台。
2. 使用 `https://rightapi.ai/codex/v1` 的 Responses 接口；兼容层的
   Chat Completions 会替换系统指令，不适合本次知识约束。
3. 聊天支持预置问题、多轮、流式输出、停止、失败重试、新对话、来源查看及复制。
   未配置或选择离线模式时明确展示“本地知识摘录”，绝不冒充模型连接成功。
4. 模型只读：不得执行充值、预约、订单修改、报修提交或人工转接。不自动上传
   账户、token、位置、订单或余额。仅发送当前问题、有限会话和检索片段；
   对手机号/Key 做尽力脱敏，界面仍提醒不要输入个人敏感信息。
5. Key 仅允许写入 Git 忽略的本地配置；示例配置保留空 Key。桌面端文件无法
   对拥有设备的人保密；对外分发前应改为服务端代理并轮换测试 Key。
6. 对话仅在内存保存，退出登录/新对话时清空并取消请求；不建立持久客服工单。

## 兼容与迁移

这是客户端本地只读扩展，原有五表、V1 TCP、业务 Mock/真实 TCP、地图模式均不变。
数据迁移为零；不启用旧扩展中的 `support.ask`、自动人工升级或客服工单表。
外部边界见[本地智能助理契约](../../contracts/client-assistant-local.md)。

## 验证

覆盖知识检索、配置隔离、请求脱敏与上下文边界、成功/失败/超时/停止、流式分片、
退出登录隔离，以及最小窗口布局。真实请求只使用通用项目问题，不使用用户业务数据。

参考：[中转站接口说明](https://docs.right.codes/docs/rc_extension/curl)、
[Responses 流式事件](https://developers.openai.com/api/docs/guides/streaming-responses)。
