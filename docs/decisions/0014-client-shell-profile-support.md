# ADR 0014：悦充统一顶栏、个人资料与客服入口拆分

状态：IMPLEMENTED（2026-09-08，用户明确授权修改）。

## 范围

仅修改用户客户端。品牌由用户指定为“悦充”。继续使用已有资料更新、头像本地存储、
测试相册和工单 V1 接口，不改数据库、计费、订单或客服服务端权限。
本决策调整 ADR 0008、0010 的客户端入口组织，不改变工单提交与处理语义。

## 页面与状态

- 全局顶栏展示悦充品牌、刷新符号和当前登录账号，手机号掩码展示。点击账号进入详细信息；
  刷新作用于当前数据页，客服对话、扫码、相册和报修填写页禁用刷新，避免清空用户输入。
  顶栏统一高 64，底部导航胶囊统一高 92、底部留白 28（均为 Qt 逻辑像素）；
  各主页面使用相同位置，不再只对首页额外上移。
  扫码相机和扫码相册嵌入“扫一扫”的内容区域，随页面缩放，继续使用同一套顶栏和底栏。
- “我的”保留订单与钱包，新增“故障报修”“我的工单”两个独立入口。
- 真人客服入口只展示客服对话，继续明确为 AI 模拟坐席。对话、报修、工单记录各自拥有
  页面实例，避免上次选中的标签页、草稿、请求结果混入另一个入口。退出登录清空三者状态。
- 从充电页报修仍携带已选桩编号；从“我的”进入可手动填写。返回再进入保留未提交草稿。
  确认提交、失败后的不可变幂等重试以及工单列表中的管理员回复沿用现有实现。
  新建报修仍是报修类型，不会变成普通客服单。
- 点击“我的”上方头像/昵称/手机号整块资料卡进入详细信息，编辑昵称后显式保存；
  返回取消未保存的编辑。头像行进入完整图片预览页，按原比例显示，再从同一测试相册更换。
  取消选图不修改头像；确认后返回头像预览并同步资料卡。保存结果和错误在当前资料子页可见。
- 点击地图空白处进入全屏时同时隐藏信息面板与底部导航胶囊，顶栏继续保持一致；
  拖动/缩放保持全屏，再次点击空白或选站恢复。地图画布保持原有尺寸和实例，避免切换时
  调整整个 WebEngine 画布；重复手势不重复设置面板状态，减少无用布局与重绘。

## 验证重点

三个客服相关入口反复切换、草稿保留、新建报修类型、未确认不提交、工单读取与会话隔离；
资料编辑保存/取消、完整头像比例、相册确认/取消、顶栏账号同步；地图全屏底栏隐藏与恢复、
画布尺寸不变；360×640 下各入口和提交按钮可操作。
