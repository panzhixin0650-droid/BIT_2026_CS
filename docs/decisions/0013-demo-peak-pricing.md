# ADR 0013：Demo 高峰加价，开始充电时锁价

状态：IMPLEMENTED（2026-09-08；用户明确批准仅做高峰涨价、按开始时间，并允许修改用户端）。

## 范围与规则

从最新 main 的订单快照机制增量实现，不引入旧扩展文档的完整计价系统。
消费者为用户端站点/充电/订单页；涉及服务端 ApplicationService、客户端 Mock API
及共享 StationDto 的可选字段。管理员仍维护基础价，不增加计价配置页面。

- 每天北京时间（Asia/Shanghai，UTC+8）08:00–11:00、18:00–21:00 为高峰，
  起点包含、终点不包含；所有站点、所有桩型统一按基础价 × 1.2。
- 其他时间基础价 × 1，不做低谷折扣、节假日/季节规则、服务费或分段计费。
- 这是课程 Demo 固定策略，不是辽宁真实电价，也不与拥堵预测联动。
- 单价先按整数分四舍五入：`(basePriceCentsPerKwh * permille + 500) / 1000`，
  其中高峰 `permille=1200`，其他时段 `1000`；乘法需检查溢出。
- `order.start` 使用服务端同一次取时，写入 UTC `startedAt` 和最终单价快照。
  预约不锁价；跨时段结束、站点调价、自动结束、重启补处理和补付款均不重算单价。
- 最终金额继续为 `(energyWh * unitPriceCentsPerKwh + 500) / 1000`；
  不改变订单状态机、余额不足流程和原子结算。

## 兼容与展示

用户 `station.list/detail` 的 `priceCentsPerKwh` 为请求时参考价；新增可选字符串
`pricingRule="DEMO_PEAK_START_V1"`，使新客户端能说明规则。缺失或未知规则时，
客户端仅展示返回价格及“以开始时单价为准”，不擅自宣称该服务器支持高峰策略。
开始充电前重新获取参考价，开始后及历史订单只展示订单的锁定单价。
价格显示不构成锁价承诺，客户端不提交倍率、单价或金额。

管理端和数据库站点价格仍为基础价。新增规则标识不持久化，订单 DTO 无变动。
旧客户端忽略新增字段，继续使用 API 返回价格和既有金额。历史订单及 Mock 历史样本
不补算加价。不新增数据库迁移，因为现有整数单价快照和金额约束已经完整承载本次规则。
将来如需动态策略或计费依据审计，另立决策/迁移，不从时间戳反推旧订单规则。

## 验证要求

两种 API 对北京时间四个边界及 UTC 跨日给出一致结果；预约转充电按开始时间；
跨时段停止、自动结束、重启后补付保留锁价；整数舍入、异常输入、旧 DTO 兼容；
用户端预览报价、错误重试、锁定单价，以及原有客户端/服务端回归测试。

契约以 [V1](../../contracts/overall-interface-v1.md) 为准；旧扩展参考仅启用本 ADR
列出的子集，不启用 `pricing_rules`、快慢充倍率或分段账单。
