# ADR 0013：地图首页、拖动面板与独立搜索

状态：IMPLEMENTED（2026-09-08，用户明确要求调研并修改）。

后续调整：本文记录初版实现；筛选入口、推荐算法、距离范围及历史展示数量已由
[ADR 0015](0015-client-location-recommendation.md) 替代；顶栏与全屏底栏行为见
[ADR 0014](0014-client-shell-profile-support.md)。

## 交互依据与范围

- [Material 标准底部面板](https://github.com/material-components/material-components-android/blob/master/docs/components/BottomSheet.md)：常驻面板不使用遮罩，保持地图可以操作。
- [Material 地图面板示例](https://m1.material.io/components/bottom-sheets.html)：地点信息与地图平移可以同时存在。
- [高德搜索与附近](https://wap.amap.com/userhelpV6/function3.html)：通过关键词或类别查找地点。该帮助属于旧版移动端说明，不视作最新版像素规范。
- [高德路线入口](https://wap.amap.com/userhelpV6/function4.html)：选定地点后进入路线规划，保留已选目的地。
- [Apple 按钮指南](https://developer.apple.com/design/human-interface-guidelines/buttons)：触控按钮应有足够的命中区域；本客户端地图工具和站点卡操作采用至少 44×44 的逻辑像素点击区域。
- [ChargePoint 找站与充电流程](https://www.chargepoint.com/drivers)：查找和筛选附近电站、查看可用情况，既有应用内充电入口，也有扫码入口。这支持当前“选定电站后选桩充电”的流程，不要求用户重复扫码。

保留现有腾讯底图及离线预览，继续使用当前浅色、绿色主题。只修改客户端，复用 V1
`station.list`、`station.detail`、`order.list`，无数据库迁移、收费状态变更或新增地图供应商。

## 页面状态

1. 首页地图铺满内容区，底部常驻面板包含拖动手柄、搜索入口与内容。
2. 面板分收起、默认、展开三档；拖动手柄跟手改变高度，松手吸附，也支持点击与键盘切换。
   收起只保留搜索入口；地图的全景、附近按钮和底图署名保持可见。
3. 默认内容为推荐站、按距离排序的附近站、最近实际充电的站。点击地图标记或列表项，
   面板切为同一电站信息卡；查看详情后在面板内选择具体桩、预约、进入独立充电页。
   返回只退出当前详情，不重置查询、位置和列表滚动。
4. 搜索入口进入应用内搜索页，输入时即时展示本次结果；提交或选择结果后记入最近搜索。
   无关键词时展示推荐、附近、上次去过的站；返回地图取消尚未提交的关键词。
5. 筛选采用独立页，区域和“仅看有空闲桩”有草稿、应用、重置、取消四个明确动作。
   返回不应用草稿，重置只清空草稿，应用后地图和列表同步。无结果可清除搜索和筛选。
   位置通过“确定位置”单独解析并立即生效；当前位置仍是演示/用户选择的位置，不声称
   Ubuntu 虚拟机已取得手机 GPS 定位。
6. 全景适配当前结果；附近回到选定位置并恢复附近尺度。常规数据刷新保留用户手动视野。

## 数据与会话

- 当前 V1 列表不分页：一次取得电站目录，在客户端对同一目录作关键词、区域、空闲条件筛选。
  关键词匹配站名、地址与区域；区域精确匹配并提供已有区域补全。
- 推荐直接使用服务返回的 `recommended`，不伪造个性化推荐；距离使用服务端请求级坐标计算。
- 搜索记录使用 QSettings，按用户 ID 隔离，去重、最近优先，最多 8 条，每条最多 80 字。
  点击清空仅删除该账号历史；退出登录清空内存中的查询、筛选和访问记录。
- “上次去过”依据当前用户订单中非空 `startedAt` 降序去重，最多展示 3 个仍符合筛选条件的站。
  只预约、取消预约、浏览详情、点击导航都不算实际到访；没有充电记录时显示空状态。
  历史读取失败明确提示，不伪称用户没有去过电站。
- 请求按 requestId 匹配，退出/切换选择时取消旧详情的接收，防止迟到响应覆盖新选择。

## 验证重点

360×640 和 480×860 的展开/收起、地图不被重建、站点卡和底栏可操作；
筛选取消与应用、空结果恢复；地图选站和搜索选站一致；搜索历史限额、去重、清空、
账号隔离；预约不算访问，充电记录才算；已有预约、导航和直接充电流程回归。

腾讯地图的默认缩放/旋转控件通过官方
[removeControl 与 DEFAULT_CONTROL_ID](https://lbs.qq.com/webApi/javascriptGL/glDoc/glDocControl)
移除，首页保留自有全景/附近按钮、腾讯署名和比例尺。原生手势缩放仍可使用。

验证记录（2026-09-08）：

- WebEngine + 扫码构建成功；客户端原有测试集分批通过。最后一轮首页地图、主窗口、
  会话恢复、TCP 结算 4 集全部通过（40.47 秒），地图导航 Xvfb 回归通过（30.93 秒）。
- 新增拖动收起/展开、搜索选站返回、八条历史去重/清空/账号隔离、充电访问记录测试；
  地图测试验证定位至附近尺度后刷新仍保留视野。
- 正常桌面图形配置下，真实腾讯 SDK 两次完成瓦片就绪检查，保存首页、收起、选站、
  详情和 360×640 搜索/筛选截图。第二次确认默认缩放/旋转控件已移除，腾讯署名保留。
- `git diff --check` 与本次文档相对链接检查通过。实际摄像头识别未重复测试；
  扫码模块回归通过，启动保留现有相机配置。附近定位仍基于演示或用户手动确定的位置。

首页底图进一步延伸到窗口底部：导航胶囊悬浮在地图之上，周围与下方露出真实底图。
信息面板仍避让导航，腾讯署名保留在底部间隙。搜索、筛选、导航路线及其他标签页继续
使用原来的内容区域，避免列表操作被底栏遮挡。

地图交互补充：拖动、滚轮、双指缩放或点击地图缩放按钮时，信息面板收起为搜索框；
点击空白处隐藏整个面板，再次点击恢复信息。隐藏期间保留选站，选中地图站点始终恢复
站点信息卡。加减缩放、全景、附近集中在右上角；推荐、附近和搜索结果的站点卡会将
地图移动到该站并放大至附近尺度。程序自动取景不触发手势收起；拖动后的合成 click
不切换面板。此逻辑在腾讯 QWebChannel 与离线地图路径中保持一致。

随后按用户补充统一选站行为：地图标记与列表卡片均定位并放大至该站附近，再显示站点信息。

面向用户的细节调整：站点预览按名称、地址、距离/空闲桩/价格、预测组织信息，文字集中排列，
底部保留“导航到站”和主操作“选桩充电”。没有空闲桩或停用时入口改为“查看电桩”，
避免暗示可以立即充电；最终可操作状态仍以详情和服务端校验为准。小屏幕的默认预览高度
结合内容最小高度计算，优先保留操作按钮。筛选页优先展示区域与空闲条件，附近搜索位置
放在后面；明确“确定位置”会立即更新，避免与尚未应用的筛选草稿混淆。

详情响应到达时只更新内容，不抢回用户已经收起、隐藏或切走的面板。

Xvfb 下 WebEngine 导航回归通过（33.81 秒）。真实腾讯 SDK 冒烟退出码 0，检查了
360×640 选站预览、搜索、筛选截图，选站卡的地址、价格和两个入口完整可见。
客户端重启后确认与保留的服务端 TCP 连接为 ESTABLISHED。
