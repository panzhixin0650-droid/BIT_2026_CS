# ADR 0018：悦充管理端视觉与数据分析

状态：已实施，待用户验收（2026-09-08，用户授权登录、工单、侧栏、表格、运营与营收分析整体优化）。

## 实施顺序

1. 登录改为左侧品牌、右侧账号密码；侧栏按总览、资产管理、业务服务、系统管理分组。
2. 统一按钮、字体、表格、滚动区域和工单列表/详情/回复布局，修复侧栏底部异常白线。
3. 基于已有权限范围内的数据扩充运营和营收图表，核对时间、金额、分母和空数据口径。
4. 检查登录成功/失败、角色权限、工单保存、统计边界和不同窗口尺寸；启动供用户验收。

## 视觉规范

- 深蓝 `#102a56` 用于导航，品牌蓝 `#2f6fed` 用于主操作与营收主序列；浅蓝 `#e8f0ff` 为选中背景。
- 页面底色 `#f3f6fb`，内容白色，分隔线 `#dfe6f0`；正文 `#243044`，次级文字 `#52637c`。
- 青绿表示可用/完成，蓝色表示充电中，紫色区分预约，琥珀表示离线/待处理，红色表示故障。
  颜色同时配标签、数量、单位或悬停说明，不只靠色块区分。
- 中文优先 Noto Sans CJK SC；正文/表格 14 px，标签 14–15 px，区块 17 px，页面标题 26 px。
  普通内容常规字重，标题与选中项 600；数值统一单位和小数位。
- 主按钮使用蓝底，次按钮使用浅底；统一圆角、间距、禁用、焦点、悬停和按下反馈。
- 原生矢量绘制品牌与导航图标，避免模糊图片与重叠特效。保留现有桌面最小窗口 1080×700。

## 管理员交互、导航与动效补充

2026-09-08 按用户后续反馈补充：

- 新增与修改管理员使用统一卡片表单、字段间距与蓝色主操作；双击只读详情，右键提供查看/修改。
- 修复管理员选中项恢复的旧页码、同页历史筛选不刷新、隐藏页被恢复信号刷新、
  站点历史展开状态被旧状态合并，以及再次登录遗留浏览历史的问题。
- 客服工单取消列表顶部独立刷新，统一使用右上角导航刷新。关联桩编号的报修工单可直接定位电桩；
  电桩右键可定位所属站点，清除遮挡目标的筛选并展开选中具体子桩。历史记录保存工单 ID、
  站点 ID 与子桩 ID；返回工单时重新校验权限并按需加载分页。普通咨询不猜测设备关联。
- 左下角账号区域仅显示显示名；角色仍用于服务端授权及管理员详情。
- 区域筛选由授权站点数据动态生成并去重，独立于当前搜索结果；多选面板有固定上下操作区、
  可滚动选项区、长名称提示与屏幕边界约束。
- 图表标题不再带“·”及其后缀；运营快照说明行移除，营收日期区间在标题下与筛选同行，使用 20 px 中等字重、`yyyy.MM.dd — yyyy.MM.dd` 格式；自定义输入另起一行。
- 运营监控增加每秒走动的北京时间，切回时校准；仅更新时钟文字，不额外读取业务数据或重播图表动画。
  日期选择增加 60/90 日，通过既有起止日期管理接口计算，前后端业务时区一致。
- 右上角刷新提供整个内容区约 420 ms 的淡入及顶部进度线反馈；不旋转按钮图标，
  不阻塞输入，不模拟业务进度；切换页面立即结束，连续点击重启而不排队。
- 总览图表采用 900 ms OutCubic：环形顺时针扫入、折线由左向右显现、条形从基线伸展。
  标签、坐标、真实数值保持稳定，不改变数据。空图无动画，隐藏时立即结束。
- 每次登录后，首次通过左侧进入各总览页播放；再次切回来不播放。
  手动刷新、切换近 7/30/60/90 日或应用自定义日期播放；后退/前进恢复页面绝不播放。
  选中“自定义”而尚未应用不会提前播放。首屏运营页在登录加载完成后播放。
- 登录背景使用浅蓝渐变、柔和光晕、低对比度电路线条与充电符号，原生绘制、随窗口缩放，
  表单依旧为不透明白色，以保证输入和错误信息易读。
- 用户授权将管理员初始/新密码长度统一放宽为 6–128，允许纯数字；确认一致、
  旧密码校验、首次改密和加盐密码摘要保留。更新同进程管理契约与 fixture，用户 TCP 不变。

## 数据分析口径

只通过现有 AdminFacade / ApplicationService 取得已授权数据，不由 UI 访问数据库。
不修改计价、历史订单、数据库或用户 TCP 契约。

- 运营显示当前电桩状态、站点占用率区间分布、异常电桩和订单当前状态；瞬时占用率不能称为历史利用率或在线率。
- 营收按已完成且有 paidAt 的订单统计，时间转换为 Asia/Shanghai；区间按支付日期取数。
  待支付金额不计入实收。电量与平均每单实收同样基于区间已支付订单。
- 运营页包含 4 张图：五类电桩状态、站点占用率区间分布、异常电桩站点 Top 8、全部订单当前状态。
  占用率分母为该站全部电桩，分子为预约及充电中电桩；可用数另行限定为运营中站点的空闲桩。
- 营收页包含 6 张图：每日实收、站点实收 Top 8、每日支付订单数、每日已支付订单电量、
  直接/预约充电实收构成、已支付订单启动时段（每 4 小时一组）。启动时段只分析所选支付区间
  的已完成订单，缺少启动时间的订单不计入时段图，不代表全部启动订单的时段分布。
- 聚合保留前一等长区间及待收的校验数据；按用户要求，界面已移除该汇总说明行，只显示与筛选同行的日期。
- 日序列补零，不平滑出不存在的观测值。站点排名明确 Top N，不暗示仅这些站点有数据。
- 保留今日、本月、累计营收的明确时间标签；区间图表统一受所选日期控制。
- 获取失败清空对应指标和图表并显示重试提示，避免把上一次成功结果当作当前结果。
- 没有历史心跳、成本或完整故障时长数据，不虚构在线率、利润、预测和故障恢复时长。

## 验证方式

- 在 Qt 6.2.4 下验证登录显隐密码、空输入、错误输入保留、局部重绘和退出登录。
- 覆盖上海日期跨日、支付区间边界、前一等长区间、待收不计实收、补零和异常输入。
- 使用 X11 虚拟屏幕检查 1080×700、1380×860、1500×950 三档窗口、八个导航页、
  图表滚动范围及侧栏底部像素；这验证当前实现，不宣称已复现所有环境中的旧白线。
- 客服摘要按纯文本显示，检查回复保存、已解决必填、角色权限、撤权清理和分页。
- 使用临时数据库/内存替身运行回归；验收启动保留实际数据库。

- 补充管理员创建/修改/只读详情测试、八页面往返与刷新隔离、同页筛选恢复、
  首次进入/再次进入/日期变化/手动刷新/历史导航动画触发矩阵。
- 密码覆盖 5/6/128/129 位、纯数字、错误旧密码、相同新旧密码和 SQLite 改密后登录。

## 调研依据

- [Apache ECharts 数据过渡](https://echarts.apache.org/handbook/zh/how-to/animation/transition/)：区分入场和更新动画，使用有限时长与缓动；本项目用原生 Qt 绘制实现。
- [Carbon 动效](https://carbondesignsystem.com/elements/motion/code/)：保持一致时长与缓动，不增加与任务无关的重复运动。
- [ChargePoint 管理平台](https://www.chargepoint.com/youve-got-the-power)：按站点状态、用电与收入组织运营视图；只采用本项目已有数据能支持的指标。
- [Carbon 图表选择](https://carbondesignsystem.com/data-visualization/chart-types/)：按趋势、分类比较和占比选择折线、条形和环形。
- [Carbon 登录模式](https://carbondesignsystem.com/patterns/login-pattern/)：左右分栏，品牌内容克制，登录相关操作集中在表单区。
- [GOV.UK 密码输入](https://design-system.service.gov.uk/components/password-input/)：可显隐密码，字段有明确标签。
- [Carbon 表格](https://carbondesignsystem.com/components/data-table/usage/)：一致行高与表头、明确工具栏和行操作。
- [Carbon 左侧导航](https://carbondesignsystem.com/components/UI-shell-left-panel/usage/)：共享导航框架和分组。
- [Carbon 数据可视化配色](https://carbondesignsystem.com/data-visualization/color-palettes/)：分类色用于区分序列，单一渐变用于量级，避免无意义多色渐变。

具体尺寸、颜色和图表组合为本项目设计选择，并非上述设计系统的强制标准。

统计卡片沿用图表 900 ms OutCubic 触发规则，以绘制层数字递增呈现载入过程。QLabel 文本与布局始终保留实际最终值，单位与小数位固定；离开页面或取新数据时结束旧动画，空值不播放。筛选弹层与选项滚动区域统一使用 #f3f6fb 底色。

总览明细跳转复用管理页面已有筛选：订单时间统一按 paidAt，营收跳转同时设置 COMPLETED、支付起止时间及站点/模式/启动时段；无时间筛选时仍可查看未支付订单。占用率按 [100%]、[70%,100%)、[40%,70%)、[20%,40%)、[0,20%) 统计有桩站点数量，并以相同分档函数筛选站点，避免临界值重复。点击明细重新读取授权数据，前进/后退恢复筛选和总览滚动位置。统计卡片及图表增加键盘激活、鼠标提示和高亮，用户管理员的资产入口禁止激活。
